# Google Play listing draft

**App name:** StudyMate

**Short description:** Plan assignments, class times, subjects and study progress in one place.

**Full description:**

StudyMate is a student planner that helps you keep academic tasks organized. Add assignment deadlines, manage a weekly timetable, track subjects, record assessment marks and review your progress from a simple dashboard.

Features:

- Keep a list of assignments, due dates and completion status.
- Organize timetable entries by day and time.
- Record marks and view subject averages.
- Review upcoming deadlines and daily timetable items.
- Use the app in English, Afrikaans or isiZulu.
- Keep core planner features available offline.

StudyMate also retrieves a daily quote when a network connection is available. The app shows a built-in quote if the service cannot be reached.
